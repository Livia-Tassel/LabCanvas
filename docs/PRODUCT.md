# LabCanvas v1.0

本机单用户科研资料工作台。表格、图片和文件拥有独立身份；分类是引用；组合是可选展示层。默认浏览结果资料，辅助资料按运行日期管理。

## 交付范围

- 项目隔离、分类树、多分类引用、搜索、类型筛选、最近导入、回收站与恢复。
- 无界画布平移/缩放/拖动/多选/布局持久化，列表与画布切换。
- 实际内容缩略图；CSV、TSV、XLSX 分页查看及单元格编辑；图片、文本、PDF 预览；其他文件下载。
- 组合、主预览、来源关系、源版本与过期提示；组合解散保留成员与分类。
- GUI 上传，独立 CLI 与 HTTP API，共享 SQLite/内容寻址不可变文件库。
- 清单导入、预检、幂等重试、跨项目约束、文件版本和冲突检测。
- 运行记录、隐藏辅助日志、模拟 AgentFS 数据；可双击启动的 macOS 应用。

## 数据与交互规则

分类删除只删除引用，条目进回收站则所有视图隐藏，恢复保留分类和画布位置。画布位置属于视图，不属于文件。导入复制文件，不依赖原路径持续存在。不同实验同名文件保持独立。更新需要明确操作并记录版本，已有图不会自动重算。演示数据必须明确标为模拟。

完整 Excel 公式计算、宏执行、多人协作、云同步与论文管理不在 v1 范围内。
