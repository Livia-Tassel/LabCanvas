# LabCanvas 验收记录

2026-11-20 在 macOS Apple Silicon 上执行。测试使用临时资料库和模拟实验数据。

| 入口 | 执行结果 |
|---|---|
| `npm run check` | 生产构建通过，9 项数据层、HTTP 和 CLI 测试通过 |
| `npm run test:e2e` | 8 条 Chromium 端到端流程通过 |
| `npm run test:desktop -- --source` | Electron 源码版通过，验证复用同资料库的本机服务 |
| `npm run package:mac` 和 `npm run test:desktop` | Apple Silicon 安装包构建通过，独立启动、保存、结束进程均通过。通过签名与 DMG 校验 |
| 旧资料库迁移 | 使用旧版程序生成组合、分类、来源和布局后升级，核对原文件、布局、缩放和 SQLite 快照 |
| CLI 并发 | 6 个进程同时以同一标识导入，得到同一个条目与初始文件版本，资料库检查通过 |

浏览器流程覆盖项目创建、重命名与切换、单文件与组合导入、框选合并与拆分、拖动归类、分类中的移除、回收站恢复及永久删除、搜索和选区同步、画布平移缩放和位置持久化。

格式验证覆盖 CSV 和 XLSX 内容缩略图、TSV 粘贴、多工作表、键盘保存、撤销和历史恢复、超过 20,000 行的只读分页，以及 SVG、TIFF、PDF、文本和原文件下载。CLI 验证覆盖清单预检、失败回滚、同标识更新、开窗同步、备份和导出。

桌面复验包含 1500 像素宽窗口、800×600 紧凑窗口、深色分类选择器、菜单命令、未保存编辑的关闭保护、组合缩略图与 PDF 渲染。截图保存在 `test-results/desktop/`。
